# AGRODECISION PK

## Human-in-the-Loop Multi-Agent AI Decision Support for Pakistani Agriculture

> AI INVESTIGATES. AI COMPARES. HUMAN DECIDES.

AGRODECISION PK is a Streamlit-based agricultural decision-support prototype designed for Pakistani farmers and growers.

The system combines:

- Farmer-provided information
- Weather/context information
- AI-assisted reasoning
- Alternative intervention comparison
- Python-based cost calculations
- Feasibility analysis
- Critic review
- Human verification
- Human decision recording
- Report generation

## Core Principle

The system does not automatically select or execute a farm intervention.

The workflow is:

Farmer evidence  
↓  
External evidence  
↓  
AI investigation  
↓  
Three alternatives  
↓  
Critic review  
↓  
Human verification  
↓  
Human decision  
↓  
Decision record
